How to write good solutions

An explainer is how you write up a solution here: the step-by-step description of how you solved a question, clear enough that a teammate with no other context can reproduce it themselves.

The goal is: You solved the problem, great. Now how do we explain so that the other person reading this with no other context can solve it as well.

If it's a question where you run a script in devtools console, say

Run this script in devtools console (Ctrl+Shift+I, click 'console' on top right).

fetch('file.json')
  .then(function (r) { return r.json(); })
  .then(function (list) { console.log(list[2].answer); });

If you downloaded a file, ran a particular script and then found the answer there, say

  1. Open your TDS folder for this GA. If you haven't already created one, create a folder called TDS, and create a subfolder called GA3 inside it.
  2. Download file-name-as.json into that folder.
  3. In that folder, create a file called run.py and paste the following code and run it.
  4. The 4th line will say something like "sample-of-what-the-answer-will-look-like", that is your answer to enter.
import json
with open('file-name-as.json') as f:
    data = json.load(f)
print("The answer is:", data["questions"][0]["answer"])

Think of it like this: You are speaking in English, but you cannot submit your assignment for some reason. There is this person who is helping you out. But that person doesn't know english.

Now there is someone who knows english and the helper's language, but they have no idea of anything else. All they can do is translate between both of you, tell literally what you told them as it is.

So, you write down each step without leaving out anything (because you have no idea if the translator will even know to include it, tho it looks obvious to you — what if they leave out a step and the other person can't solve the question for you?)

Spell out every step, one by one, and help the person solve the assignment is it.

If you are using AI/AI agents to solve it for you, tell the agent to write the how to solve it along with scripts and paste it there instead. YOU MUST NOT submit an AI script without verifying it yourself as correct. Don't include the paddings AI uses and tell it to get to the point. Copy paste this text to the AI so it knows what we are looking for.
